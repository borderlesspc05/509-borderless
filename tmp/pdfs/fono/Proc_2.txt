HABILIDADES COMUNICATIVAS:
Habilidades dialógicas ou conversacionais
( ) Inicia a conversação/interação ausente
( ) Aguarda seu turno (não se precipita, interrompendo o interlocutor)
( ) Participa ativamente da atividade dialógica (alternância de turnos na interação)
Funções comunicativas
( ) Instrumental - solicitação de objetos, ações (“dar um brinquedo; abrir uma porta”)
( ) protesto – interrupção com fala ou ação uma ação indesejada (“pára”)
( ) interativa – uso de expressões sociais para iniciar ou encerrar a interação (“oi, tchau”)
( ) nomeação – nomeação espontânea de objetos, pessoas ações (“ó cachorro”)
( )informativa – comentários, informações espontâneas na interação (“ó meu sapato”)
( ) heurística – solicitação de informação ou permissão (“pode pegar? / Cadê a bola?)
( )narrativa – presença de turnos narrativos (“o príncipe beijou a princesa e casou”)
Meios de comunicação Verificar se os meios atingiram níveis de simbolização
Para crianças sem oralidade:
( ) somente gestos não simbólicos elementares(pegar na mão e levar, puxar, cutucar)
( ) gestos não simbólicos convencionais (apontar, negar com a cabeça, gesto de vem cá)
( )gestos simbólicos (gestos que representam ações, objetos, idade)
Para crianças com oralidade:
( ) somente vocalizações não articuladas
( )vocalizações não articuladas e articuladas com entonação da língua (jargão)
( )palavras isoladas contextuais (ligadas ao contexto imediato)
( ) palavras isoladas referenciais (não ligadas ao contexto imediato)
( ) frases “telegráficas” com 3 ou mais palavras de categorias diferentes
( ) relato de experiências imediatas com frases com 5/6 palavras sem omissões de elementos (“o
que você está fazendo? Eu estou ...”)
( )relato verbal de experiências não imediatas (“o que aconteceu na escola? Teve um dia ...”
Níveis de contextualização da linguagem
( )linguagem refere-se somente à situação imediata e concreta
( )linguagem descreve a ação que está sendo realizada e faz referências ao passado e / ou ao futuro
imediato, sem ultrapassar o contexto imediato

( ) linguagem vai além da situação imediata, referindo-se a eventos mais distantes no tempo (evoca
situações passadas e antecipa situações futuras não imediatas)
COMPREENSÃO VERBAL
( ) Não apresenta respostas à linguagem
( ) responde assistematicamente
( ) Atende quando é chamada
( ) Compreende somente ordens com uma ação
( ) Compreende somente ordens com até duas ações
( ) Compreende ordens com 3 ou mais ações, solicitações e comentários somente quando se
referem a objetos, pessoas ou situações presentes
( ) Compreende ordens com 3 ou mais ações, solicitações e comentários que se referem a objetos,
pessoas ou situações ausentes
ASPECTOS DO DESENVOLVIMENTO COGNITIVO
Formas de manipulação dos objetos
( )Não se interessa pelos objetos
( )Desiste da atividade quando surge algum obstáculo
( ) Atua sobre os objetos de modo repetitivo ou estereotipado (põe tudo na boca, joga)
( )Explora os objetos por meio de poucas ações
( )Tempo de atenção curto, explorando os objetos de modo rápido e superficial
( ) Persiste na atividade quando surge algum obstáculo, tentando superá-lo
( ) Explora os objetos um a um de modo diversificado
( ) Atua sobre dois ou mais objetos ao mesmo tempo relacionando-os de maneira diversificada
Nível de desenvolvimento do simbolismo
( ) Não apresenta condutas simbólicas, somente sensório-motoras
( ) Faz uso convencional dos objetos
( ) Apresenta esquemas simbólicos (centrados no próprio corpo)
( ) Usa bonecos ou outros parceiros no brinquedo simbólico
( ) Organiza ações simbólicas em uma seqüência
( ) Cria símbolos fazendo uso de objetos substitutos ou gestos simbólicos para representar objetos
ausentes
( ) Faz uso da linguagem verbal para relatar o que está acontecendo na situação de brinquedo
Nível de organização do brinquedo
( ) manipula os objetos sem uma organização dos mesmos
( ) organiza as miniaturas em pequenos grupos, reproduzindo situações parciais, mas sem uma
organização de todo o conjunto (ex: cadeiras colocadas em volta da mesa)
( ) faz pequenos agrupamentos de dois ou três objetos (ex: xícara ao lado da colher)
( ) enfileira os objetos (coloca um ao lado do outro, como se fizesse uma fila ou linha)
( ) organiza os objetos distribuindo-os de modo a configurar os diversos cômodos da casa
( ) agrupa os objetos em categorias definidas, formando classes [ 4 ] seria os objetos de acordo
com diferenças (ex.: do maior para o menor)
